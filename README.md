# Different stages of Git:
# # Working Directory# #
### Working Directory is a current state of the project files. Its a staging Area; place where you can group changes before committing them. ###

### Staging acts as a prep zone for changes before they are committed to the main repository. This guide provides an in-depth look at how to interact with the staging area, including adding, modifying, and removing changes.###

### Commit includes a comment that records information about the changes, and usually becomes the new tip of the branch. Git doesn't automatically include any files you move, change, or delete in a commit. This prevents you from accidentally including a change or file, like a temporary directory. ###
